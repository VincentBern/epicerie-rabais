# Rabais d'épicerie – Maxi vs IGA

Comparaison hebdomadaire des circulaires Maxi et IGA (région de Québec), publiée avec GitHub Pages.

- `data/AAAA-MM-JJ.json`: données d'une semaine (une ligne par produit)
- `build_page.py`: génère `index.html` et `archive/` à partir des fichiers `data/`

Prix tirés des circulaires et des sites des épiceries, à valider en magasin. Projet personnel, non affilié à Maxi ni à IGA.
